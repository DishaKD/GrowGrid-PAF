# 🌱 GrowGrid – Skill Sharing & Learning Platform

**GrowGrid** is a scalable, full-stack **Skill Sharing & Learning Platform** designed to empower individuals to share and learn real-world skills through a peer-to-peer system. The application was architected using a **microservices** approach, following **Domain-Driven Design (DDD)** principles and implemented with **Spring Boot** for the backend and **React.js** for the frontend.

<br/>

## 🧰 Tech Stack

### 🔧 Backend
- **Spring Boot (Java)** – Microservices architecture  
- **Spring Security + JWT** – Authentication & Authorization  
- **REST APIs** – Secure and modular endpoint design  
- **MySQL** – Persistent storage  
- **Docker** – Containerization for microservices  
- **Spring Cloud / Eureka / Config Server** *(optional for scalability)*

### 🎨 Frontend
- **React.js** – Component-based UI  
- **Axios** – API communication  
- **Tailwind CSS / Bootstrap** – UI styling  
- **React Router** – Client-side navigation

<br/>

## 🧠 Architecture

- ✅ **Microservices** – Separation of concerns and scalability  
- ✅ **Three-layer DDD structure**:
  - **Application Layer**: Controllers and Services  
  - **Domain Layer**: Core business logic and models  
  - **External Layer**: Repositories, external APIs, and infrastructure

<br/>

## ✨ Core Features

- 👤 **User Registration & Login**  
- 🛡️ **JWT-Based Authentication**  
- 📝 **Post Creation** – Share knowledge and skills  
- 🔄 **Skill Exchange** – Interact with other users and exchange skillsets  
- 📦 **Modular Microservices** – Independent deployment and scaling  
- 🐳 **Dockerized Services** – Seamless and consistent deployment environments  
- 🧪 **Secure & Tested RESTful APIs** for all interactions
